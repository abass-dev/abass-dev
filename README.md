# Hi there 👋, I'm Abass Alzouma

I'm a **digital creator, web developer, graphic designer, motion designer, videographer, and video editor** based in Niger.

I create digital experiences that combine **design, technology, video, and creativity**. Through **Wane Crea**, I work on websites, branding, graphic design, motion design, video production, and digital communication.

I have a strong background in web development and currently focus mainly on **Next.js and modern web technologies**, while continuing to explore new tools and creative workflows.
